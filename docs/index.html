Installation

Recommandé

macOS & Linux — une seule commande

curl -fsSL https://raw.githubusercontent.com/light-editor-vidz/light-editor-vidz/main/install.sh | bash
macOS → Homebrew Ubuntu / Debian → .deb Autres Linux → AppImage
  • macOS — installe via un tap Homebrew personnel et récupère ffmpeg comme dépendance.
  • Linux — installe le .deb sur Debian et Ubuntu, sinon l’AppImage dans ~/.local/bin, et ajoute ffmpeg s’il manque.

Installation manuelle

macOS
brew install light-editor-vidz/tap/light-editor-vidz
Linux (.deb)
curl -fsSL -o light-editor-vidz.deb "$(curl -fsSL https://api.github.com/repos/light-editor-vidz/light-editor-vidz/releases/latest | grep -o 'https://[^"]*_amd64\.deb' | head -1)" && sudo apt install ./light-editor-vidz.deb
Linux (AppImage)
mkdir -p ~/.local/bin && curl -fsSL -o ~/.local/bin/light-editor-vidz.AppImage "$(curl -fsSL https://api.github.com/repos/light-editor-vidz/light-editor-vidz/releases/latest | grep -o 'https://[^"]*_amd64\.AppImage' | head -1)" && chmod +x ~/.local/bin/light-editor-vidz.AppImage

ou récupérez le .deb ou l’AppImage sur la page des releases.

Désinstallation

Recommandé

macOS & Linux — une seule commande

curl -fsSL https://raw.githubusercontent.com/light-editor-vidz/light-editor-vidz/main/uninstall.sh | bash

Retire l’application quelle que soit la façon dont elle a été installée. Vos projets et réglages sont conservés.

Désinstallation manuelle

macOS
brew uninstall --cask light-editor-vidz
Linux (.deb)
sudo apt remove light-editor-vidz
Linux (AppImage)
rm ~/.local/bin/light-editor-vidz.AppImage
